# Break and Steal an Egg Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已确认的设计与本地资料实现为有真实内容、四语言、可部署的 Roblox 游戏攻略网站。

**Architecture:** 采用 Node.js 静态生成，正文、路由与翻译独立于共享模板。所有内链、搜索索引、语言切换和站点地图从统一页面注册表生成。浏览器脚本仅负责渐进增强，正文无需 JavaScript 即可读取。

**Tech Stack:** Node.js 22+、ES modules、HTML、CSS、原生 JavaScript；使用 Node.js 内置测试运行器，尽量不引入第三方运行依赖。

**Spec:** `docs/superpowers/specs/2026-10-17-egg-wiki-design.md`

## Global Constraints

- 默认亮色，奶油白 `#FFFBF0`、金黄色 `#F0AD05`、深蓝文字 `#172033`；暗色背景 `#111827`。
- 首页英文路径 `/en/`；其余语言使用 `/pt-br/`、`/es/`、`/id/`。
- 八个首页模块沿用资料文件顺序，并均提供实际内容页。
- 28 个关键词保留内容规划映射，不将缺乏证据的关键词自动生成为空壳文章。
- 不虚构兑换码、价格、概率、人物身份和实时数据；2026-10-17 是资料核查日期。
- 官方图片使用本地文件；玩家视频标为 Community Gameplay，点击后加载。
- 不展示对标网站或第三方攻略站的引用链接；风险关键词不进入公开内容。
- 无数据库、登录、账号交易、自动播放和第三方分析脚本。
- 部署域名未确定时不生成假 canonical；通过 SITE_URL 设置真实地址后再生成正式 SEO 绝对链接。
- 保留用户原始资料；生成文件只写入明确的输出路径，不递归清理工作区。

## Review Focus

1. 搜索特殊字符、空字符串和不存在的词，应显示正常结果或可理解的空状态，不出现 HTML 注入。
2. 用户在内页切换语言，应进入同一内容的对应语言页；四语言目录与 hreflang 必须一致。
3. localStorage 不可用、图片加载失败、禁用 JavaScript 时，正文、导航和内容仍可使用。
4. 未知路径、带查询参数的路径、输出文件缺失时，应返回适当状态且无断链。
5. 375px 屏宽、键盘操作、暗色模式下，菜单、搜索和文章阅读不能横向溢出或不可操作。

### Task 1: 本地内容、路由与素材

**Files:** Create `package.json`, `content/en.json`, `content/pt-br.json`, `content/es.json`, `content/id.json`, `content/articles.mjs`, `content/keyword-map.json`, `src/routes.mjs`, `scripts/prepare-assets.mjs`, `tests/content.test.mjs`, `public/assets/`。

**Interfaces:**
- `locales = ['en', 'pt-br', 'es', 'id']`。
- `pages` 为 `{slug, category, titleByLocale, summaryByLocale, sectionsByLocale, sources, reviewedAt}` 数组；section 为 `{id, heading, paragraphs, items?}`。
- `pagePath(locale, slug = '')` 返回带尾斜线的 `/locale/slug/` 路径。
- 翻译 JSON 包含首页、导航、搜索、FAQ、页脚和无兑换码状态；`home.explore.modules` 保留八个模块。
- `keyword-map.json` 每项包含原始 keyword、targetSlug 与 evidenceStatus；仅确证内容进入公开搜索索引。

- [ ] Step 1: 编写内容测试，断言四种语言存在、八个模块顺序和路径一致、必需文章均有独立正文、28 个关键词映射无遗漏、codes 不包含伪造码。
- [ ] Step 2: 执行 `node --test tests/content.test.mjs`，确认因尚未存在内容或路由实现而失败。
- [ ] Step 3: 从原始 Markdown 导入首页和模块资料，手动整理实际攻略正文和三套翻译；保留事实、实用建议和证据边界的区别。

### Task 2: 完整静态页面与视觉

**Files:** Create `src/templates.mjs`, `src/styles.css`, `scripts/build.mjs`, `tests/site.test.mjs`, `dist/`。

**Interfaces:**
- `renderPage({locale, page, origin, registry})` 返回完整 HTML 字符串；首页 page 为 null。
- `escapeHtml(value)` 转义来自内容与搜索的文本；JSON-LD 序列化时安全处理 HTML 结束标签。
- `node scripts/build.mjs` 输出页面、静态资源、语言搜索索引、404、robots 和 sitemap；SITE_URL 为可选部署 origin。
- `/search-index.<locale>.json` 每项为 `{title, summary, category, href, keywords}`。

- [ ] Step 1: 编写构建测试，断言 HTML 正文不依赖脚本、title/description/lang 存在、内链有对应文件、四语言 alternates 对称、结构化数据可解析、无虚构 canonical。
- [ ] Step 2: 执行 `node --test tests/site.test.mjs`，确认构建器缺失时失败。
- [ ] Step 3: 实现首页和通用文章模板；完成导航、主栏、侧栏、八模块、FAQ、点击视频区域、页脚、来源和历史数据标记。
- [ ] Step 4: 实现目录、社群、隐私、条款与 404 模板，并为所有语言生成真实内容。
- [ ] Step 5: 编写响应式 CSS、深浅色变量、焦点样式、reduced-motion 和 375px 单列布局；使用本地图片与 favicon。
- [ ] Step 6: 实现构建命令与 sitemap/robots。无 SITE_URL 的本地版本不伪造正式绝对地址；发布时用实际地址重建。
- [ ] Step 7: 执行 `node scripts/build.mjs` 和 `node --test tests/site.test.mjs`，确认构建和内链校验通过。

### Task 3: 搜索、主题、菜单与语言切换

**Files:** Create `src/client.mjs`, `src/search.mjs`, `tests/interactions.test.mjs`, `scripts/serve.mjs`。

**Interfaces:**
- `searchPages(items, query, category = '')` 返回标题、摘要、关键词匹配的条目；使用文本匹配，不将查询插入 HTML。

- `node scripts/serve.mjs` 仅监听 `127.0.0.1:4173`，服务 dist；存在文件返回正确 Content-Type，未知路径返回自定义 404 和 HTTP 404。
- 主题首选项键为 `egg-wiki-theme`，仅保存 `light` 或 `dark`。

- [ ] Step 1: 编写搜索测试：大小写、空输入、无匹配、特殊字符、分类过滤；编写服务器测试：首页 200、资源类型、未知路径 404、查询参数、禁止路径越界。
- [ ] Step 2: 执行 `node --test tests/interactions.test.mjs`，确认缺少实现时失败。
- [ ] Step 3: 实现搜索与无结果状态、移动菜单 Escape 关闭、主题切换与存储失败回退、点击加载隐私增强视频；FAQ 使用原生 details。
- [ ] Step 4: 实现语言切换同页保持和本地预览服务器；无 JavaScript 时语言及文章链接照常可用。
- [ ] Step 5: 执行交互测试和完整构建，确认通过。
- [ ] Step 6: 浏览器检查首页及文章，测试搜索、空结果、主题刷新保持、语言同页切换、视频加载和菜单键盘操作；375px 检查无横向溢出。若浏览器能力缺失，记录实际限制。
