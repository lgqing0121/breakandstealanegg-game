## 2、网站主题色与默认模式

**建议默认亮色：奶油白背景 + 金黄色主色 + 深蓝文字。**

这是围绕蛋、现金收益和轻松收集玩法的设计建议。金黄色适合主按钮、重点数据和稀有度提示；按钮搭配深色文字，避免黄色底上的白字难读。

```css
/* 导航页主题色 - 亮色主题 */
[data-theme="light"] {
  --nav-theme: 43 96% 48%;        /* 金黄色，约 #F0AD05 */
  --nav-theme-light: 45 100% 64%; /* 浅蛋黄色，约 #FFD147 */
}

/* 导航页主题色 - 暗色主题 */
[data-theme="dark"] {
  --nav-theme: 45 100% 60%;       /* 明亮金黄色，约 #FFCC33 */
  --nav-theme-light: 47 100% 72%; /* 浅金黄色，约 #FFE070 */
}
```

配套背景建议：亮色使用 `#FFFBF0`，暗色使用 `#111827`，正文文字分别使用 `#172033` 和 `#F8FAFC`。

排序依据与落地建议：

- **英语**：优先覆盖原始游戏名搜索，以及英文玩法视频带来的攻略需求。
- **巴西葡萄牙语**：优先测试巴西市场。Roblox 官方确认巴西拥有数百万用户，并为其建设本地数据中心，但这不等于该游戏的语言流量统计。[Roblox 官方说明](https://about.roblox.com/newsroom/2025/09/roblox-rdc-2025)
- **西班牙语**：覆盖拉美与西班牙用户；先翻译新手指南、基地收益、逃离守卫与升级选择页面。
- **印度尼西亚语**：作为第四批测试语言。Roblox 官方回顾提及印尼用户具有突出的部分玩法搜索需求，可作为平台层面的参考。[Roblox 搜索回顾](https://about.roblox.com/en-nz/newsroom/2025/12/roblox-replay-decoded-search-style)
